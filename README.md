# Nkwa — Portfolio Starter

A static, mobile-responsive editorial portfolio built for GitHub Pages. No npm, frameworks, or build system are required.

## What's inside
- `index.html` — homepage with three selected projects
- `about.html` — short biography
- `projects/lions-services.html` — detailed Lions Services case study
- `assets/lions/` — extracted original presentation slides and **cropped** demo screenshots
- `css/style.css` — responsive design system
- `js/main.js` — optional future enhancements
- `.nojekyll` — serves static assets as-is

## Publish on GitHub Pages
1. Sign in to your GitHub account. Confirm the exact username first.
2. Make a **public** new repository named `<your-username>.github.io` (e.g. `onwudiwee.github.io` if your username really is `onwudiwee`).
3. Download and unzip this starter package, then upload **all files and folders inside** `nkwa-portfolio-starter`, including `index.html`, into the repository root. Do not upload just the enclosing folder.
4. Commit files to `main`.
5. Open repository **Settings → Pages → Build and deployment**, select **Deploy from a branch**, `main`, `/(root)`, then **Save**.
6. Open `https://<your-username>.github.io/` after GitHub reports the deployment succeeded.

Reference: https://docs.github.com/en/pages/quickstart

## Before publishing publicly
- Check name, bio, email, and links. Replace or remove any detail you don't want public.
- The demo video is **not included** because the supplied recording shows phone numbers/account fields. Review/redact it and add a privacy-safe video later.
- Team repository link may be private: verify it.
- Add teammates' portfolio links or clearly indicate when unavailable.
- Confirm the Code for Good project is allowed for your course Assignment #4.
- The 4% and 60M+ statistics are visible on the original historical presentation slide; **they are not independently sourced here**. Do not present them as verified claims without original sources.
- Replace the personal reflection draft with your genuine wording.
- Verify any accessibility statements with real testing before claiming conformance.
